## 一、赛题拆解与我们的定位

发榜方要的是一套 **"分布式感知 + 云边协同推理 + 全局优化决策"** 的完整系统，核心是打破"以云为中心的集中式 AI"，让感知、推理、决策在**端/边/云**之间合理分工。赛题明确要求实现三个核心功能，正好对应我们的三块工作：

| 赛题核心功能 | 对应我们的模块 | 负责团队 | 技术底座 |
|---|---|---|---|
| ① 边缘实时感知与**轻量化推理**（国产大模型压缩、边侧信创可部署） | 模块 A：自适应轻量化 | 东方老师组（2 人） | AutoTailor（SuperNet + TailorIR 图编译 + learning-free 预测器） |
| ② **云边协同推理与任务调度**（大小模型互补、在线寻优） | 模块 B：云边协同 | 周老师组（3 人） | MV-ViT + 云端 VLM 知识预言机 + 解耦提示 + Lyapunov 混合 Actor-Critic |
| ③ **全局决策优化与一致性保障**（长周期更新、局部贪婪 vs 全局最优） | 模块 C：持续学习与全局决策 | 周老师组（3 人） | 云端 Replay Buffer 持续学习 + 多节点一致性仲裁 |

**我们的核心优势**：模块 A 和模块 B/C 各自都有一篇顶会级别的成熟工作（AutoTailor、周组建模+理论证明），**不是从零起步**。这次比赛的胜负手不在"造轮子"，而在于把两套现成的强技术**在系统层面咬合成一个闭环**，并用赛题要求的量化指标证明它。

## 三、技术总体架构（端–边–云三层）

```
                          ┌──────────────────── 云 Cloud ────────────────────┐
                          │  全量大模型 / VLM「知识预言机」                     │
                          │  · 生成解耦视觉提示 Penv（环境提示）+ ωt（空间先验） │
                          │  · Replay Buffer 持续学习 → 长周期模型更新(DoRA)    │
                          │  · 全局上下文 → 多节点决策一致性仲裁               │
                          └───▲───────────────────────────┬──────────────────┘
              上行 Squery(关键帧) │ ut≠0 触发            │ 下行：Penv/ωt(轻量) 或 重训练权重差量
                                 │                       ▼   （下发的权重先过 AutoTailor 再编译）
                          ┌──────┴───────────────────────────────────────────┐
                          │                    边 Edge 节点 i                  │
                          │  轻量 MV-ViT（AutoTailor 产出的 SuperNet 变体族）   │
                          │  · 多粒度资源调度：vt 视角选择 / kt token 剪枝     │
                          │  · 漂移感知 Edrift(t)（香农熵，零额外算力）        │
                          │  · Lyapunov 混合 Actor-Critic 在线选"操作点"       │
                          └──────▲───────────────────────────────────────────┘
                                 │ V 路同步摄像头 / 传感器
                          ┌──────┴──────┐
                          │   端 Device  │  多源异构感知数据
                          └─────────────┘
```

- **模块 A（东方组，AutoTailor）**：把国产开源大模型（如 DeepSeek）/ MV-ViT，通过计算图引导编译（TailorIR）压成一族权重共享的 SuperNet 变体，并用 learning-free 预测器为每个变体打上「时延 / 内存 / 精度」标签。产出：边侧信创可部署（NCNN/FP16）、TTFT↓75%、内存≤1.5GB、能力保持 80–90% 的**可运行时切换的模型变体族**。
- **模块 B（周组，云边协同）**：边侧 MV-ViT 实时推理，云端 VLM 当"知识预言机"下发解耦提示；边侧用 Lyapunov 混合 Actor-Critic（Actor 做 NOP 保序量化离散探索，Critic 做 KKT 注水闭式解）在带宽约束下在线求解 `at={vt,ut,kt}`，保证端到端≤0.2s、网络波动保持率≥90%。
- **模块 C（周组，持续学习+全局决策）**：云端 Replay Buffer 捕捉环境演变、长周期重训练（ut=2），并对重叠感知区域的多节点做全局一致性仲裁，解决"局部贪婪 vs 全局最优"冲突。

## 四、技术闭环设计（碰头会重点 ★）

赛题的分不在"三块各自跑得好"，而在"三块能不能**咬合成一个自洽的闭环**"。这也是 40 分技术效果 + 25 分方案完整性 + 20 分一致性的关键。三个咬合点：

### 闭环点 ① 轻量化 ↔ 调度：**预测器即代价模型**（打通 A→B）
- **问题**：周组的调度优化里有两个函数需要"知道每个动作要花多少算力、精度掉多少"——计算成本 `Costcomp(kt,vt)`（凸函数）和精度代理 `Accuracy(kt,vt)`。这两个函数原本是建模假设出来的。
- **闭环做法**：AutoTailor 产出的**每个 SubNet 变体自带 (latency, memory, accuracy) 预测标签**。周组的 Actor-Critic 在运行时不再"假设"代价，而是**直接把 AutoTailor 的 learning-free 预测器当作真实代价/效用模型**，把 `{vt, kt}` 决策映射到 AutoTailor 变体空间里的一个"操作点"。
- **接口契约（必须先定）**：AutoTailor 输出 `{SubNet_id → (TTFT, mem, acc_surrogate)}` 查找表 + 可 NCNN/FP16 执行的权重；调度器按 `{vt,kt}` 索引对应 SubNet 并切换。
- **一句话**：轻量化不是"一次性压缩"，而是给调度器提供一份**运行时可切换的、带成本标签的操作点菜单**。

### 闭环点 ② 持续学习 ↔ 轻量化：**更新即再编译**（打通 C→A→边侧）
- **问题**：当漂移 `Edrift(t)` 升高、云端触发更新时，下发到边侧的东西**必须仍然是边侧可部署、内存达标的**，否则更新完就跑不动了。
- **闭环做法**（分三级，省带宽）：
  - `ut=1`（环境更新）：只下发轻量 **Penv + ωt**，不回传权重，上行开销极低；
  - `ut=2`（重训练）：云端 Replay Buffer 持续学习 / **DoRA 高效微调** 后，新模型**必须重新过 AutoTailor 流水线**（TailorIR 解析 → SuperNet → 预测器重建），以**权重差量**下发边侧热更新。
- **接口契约**：云端所有产出的更新模型统一走 AutoTailor 编译，保证下发变体仍满足 TTFT/内存约束；learning-free 预测器让"再编译"**无需重新耗时 profiling**。
- **一句话**：闭环 = 漂移感知 → 云端学习 → AutoTailor 再轻量化 → 边侧热更新。

### 闭环点 ③ 全局 ↔ 局部：**一致性仲裁**（模块 C 需新增 ★★）
- **问题**：单节点 Actor-Critic 只保证本地"效用-带宽"最优（局部贪婪）；但赛题要求**多个重叠感知/关联任务的边缘节点之间决策冲突≤5%、冲突解决≥90%**。当前建模是单节点的，**这一层要新建**。
- **闭环做法**：云端全量 VLM 基于跨节点全局上下文做**一致性仲裁**——检测重叠区域决策冲突（如同一目标被相邻路口重复/矛盾判定），下发一致化的决策逻辑；边侧保留冲突回滚机制。
- **一句话**：这是把"单点智能"升级为"全局智能"的关键，也是拿满一致性 20 分的地方。

### 系统数据流闭环（一句话总览）
> **感知**（边侧 MV-ViT 轻量推理）→ **漂移检测**（Edrift）→ **调度**（Lyapunov Actor-Critic 在 AutoTailor 操作点菜单里在线寻优）→ **协同**（ut 触发云端下发 Penv/ωt 或重训练）→ **云端持续学习 + 全局一致性仲裁** →（AutoTailor 再编译）→ **热更新下发** → 回到感知。
