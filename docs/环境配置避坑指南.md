# EdgeCloud 环境配置指南

## 推荐环境

| 用途 | 推荐配置 | 说明 |
|---|---|---|
| 快速验证与网页演示 | Python 3.11、CPU、8 GB 内存 | 无需数据集和 checkpoint |
| 边缘模型评测 | NVIDIA GPU、显存 ≥6 GB | 用于 TTFT、显存和完整 test |
| 云端教师与 Adapter 训练 | NVIDIA GPU、显存 ≥24 GB | InternViT-6B 可按模型卡选择精度与设备数 |
| 调度与网络仿真 | Python 3.11、CPU | 主要依赖 NumPy/Pandas |

正式复现环境、数据和权重布局见根目录 [REPRODUCE.md](../REPRODUCE.md)。

## 安装

```bash
python3.11 -m venv .venv
source .venv/bin/activate                # Windows: .venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

若使用 NVIDIA GPU，应先根据 CUDA 版本从 PyTorch 官方渠道安装匹配的 `torch` 和 `torchvision`，再安装其余依赖。

## 无数据环境验证

```bash
python scripts/verify_env.py
```

该命令默认随机初始化 ViT-Small，不需要数据集、训练 checkpoint 或网络下载。它验证四视图前向、Token 剪枝、视角休眠和 CPU 参考计时。需要验证 timm 的 ImageNet 预训练权重下载时使用：

```bash
python scripts/verify_env.py --pretrained
```

## 常见问题

### 预训练权重下载失败

`--pretrained` 会由 timm 从模型托管站点下载权重。离线环境应先按 Release 说明准备缓存，或省略该参数执行结构验证。

### CUDA 与 PyTorch 不匹配

确认 `python -c "import torch; print(torch.__version__, torch.version.cuda, torch.cuda.is_available())"` 输出符合预期。不要混用不同 CUDA 主版本的 wheel。

### 数据路径错误

所有正式脚本均应通过 `--dataset-path`、`--baseline-checkpoint`、`--adapter-checkpoint` 等参数传入路径。建议使用仓库根目录下的相对路径，避免写入特定服务器目录。

### 结果目录已存在

部分验收脚本为防止覆盖正式证据，会拒绝写入已有目录。复现时使用新的 `artifacts/*/reproduced/` 目录。
