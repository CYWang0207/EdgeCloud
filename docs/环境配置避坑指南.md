# 挑战杯项目环境配置避坑指南

> 队长实测整理，2026-07-28。组员照此操作可省去大量踩坑时间。

---

## 一、硬件要求

| 用途 | 显卡要求 | 说明 |
|------|---------|------|
| 跑训练（train.py 等） | **必须有 NVIDIA 独显**，显存 ≥ 6GB | CPU 跑一个 epoch 要几小时，不现实 |
| 跑推理/验证（test.py、verify_env.py） | CPU 也能跑 | 单帧约 180ms，验证逻辑够用 |
| 跑 RL 调度仿真 | CPU 即可 | 主要是数值计算，不依赖 GPU |

**组长本机情况**：只有 Intel UHD 770 核显，无 N 卡。能跑推理验证、能跑 RL 仿真，但跑不了训练。训练任务交给有 N 卡的组员。

---

## 二、Python 版本

- **推荐 Python 3.10 或 3.11**（PyTorch 官方支持，最稳）
- Python 3.14 也能装上 torch 2.13.0（有 cp314 wheel），但 **pandas 在 3.14 上有 DLL 加载问题**，影响读 CSV 的评估脚本
- 组长用 3.14 跑通了核心链路（torch/timm/torchvision），但评估脚本用到的 pandas 需降级或换 3.11

**建议**：有 N 卡的组员装 Python 3.11，一劳永逸。

---

## 三、依赖安装命令

```bash
# 1. 升级 pip
python -m pip install --upgrade pip

# 2. 装 PyTorch（按你的显卡选一个）

# 有 NVIDIA 显卡（推荐，按 CUDA 版本选，示例 CUDA 12.1）：
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121

# 无 NVIDIA 显卡（CPU 版）：
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu

# 3. 装其他依赖
pip install timm tqdm matplotlib

# 4. pandas（评估脚本用，3.14 上有问题，建议 3.11 才装）
pip install pandas
```

验证安装：
```bash
python -c "import torch, torchvision, timm, tqdm, matplotlib; print('torch', torch.__version__, 'cuda', torch.cuda.is_available())"
```

## 四、核心避坑点

### 坑 1：import 路径问题（drift_dataset 找不到）

仓库重构后，`module_edge_perception/` 下的 `train_retrain_drift.py`、`train_token_prompt.py` 会报找不到 `drift_dataset`。

**解决方案**：见飞书群公告《import 路径修复说明》。最简单：把 `module_scheduling/EdgeCloud_RL/drift_dataset.py` 复制一份到 `common/`，改 sys.path 指过去。

### 坑 2：预训练权重自动下载

`model.py` 里 `timm.create_model(..., pretrained=True)` 首次运行会从 HuggingFace 下载 ViT 预训练权重（约 80MB）。网络不通会卡住。

**解决方案**：
- 确保网络能访问 huggingface.co（可能需要梯子）
- 或提前手动下载权重放到 `C:\Users\<用户名>\.cache\huggingface\`

### 坑 3：数据集 ModelNet40 缺失

代码默认数据集路径 `./data/modelnet40v2png_ori4`，但仓库不存数据集。

**现状**：组长本机该数据集不存在，需找学长要网盘链接或自行下载 ModelNet40v2（约 2GB）。

### 坑 4：checkpoint 权重为空

学长传的 `checkpoints/*.pth` 文件目前都是 0 字节占位符，真实权重未上传。需找学长要真实权重或重新训练。

## 五、环境验证脚本（不依赖数据集和权重）

在仓库根目录放一个 `verify_env.py`，用随机数据验证整条链路（已验证通过）：

```bash
python verify_env.py
```

它会：
1. 构建 MV-ViT 模型（自动下载预训练权重）
2. 随机输入推理，验证前向传播
3. Token 剪枝 + Prompt 注入 + 视角休眠 协同推理
4. CPU 单帧计时

通过即说明代码链路完整、环境配置正确。**不需要数据集和 checkpoint 就能验证环境。**
