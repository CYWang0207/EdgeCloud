# 多视图漂移校正 Adapter 实验记录（2026-08-05）

## 结论

阶段性核心目标已经实现：在 BoxCars116k 的 16 类品牌识别任务中，使用真实标签监督的
`general` AdaptFormer 能在同一批验证样本、同一漂移随机种子与相同强度下，稳定改善五类
合成漂移的准确率，同时没有损害干净域表现。

这验证了《[漂移校正Adapter方案](漂移校正Adapter方案.md)》中的核心映射：

```text
漂移后的多视图输入 -> Adapter 校正后的特征 -> 更接近干净域的品牌分类结果
```

不过，方案中“专家 Adapter bank + 真实环境 VLM 路由”的完整系统尚未完成，也不应在当前结果
下直接宣称完成：本次只训练了统一的 `general` Adapter，使用的是合成漂移的 oracle 类型，
没有训练或比较 `blur`、`noise` 等专家，也没有接入 VLM 的受约束退化识别。

|---|---|---|

| 训练统一与按类型 Adapter 并对比 | 部分完成 | `general` 已训练并与 baseline 同条件对比；专家 Adapter 尚未训练。 |

## 实现与训练方法

本次没有采用 VLM 品牌软标签蒸馏。原因是通用 VLM 对 BoxCars 的 16 类细粒度品牌判断不是
可靠教师；训练直接使用 BoxCars 的真实 `make` 标签。

每个训练样本生成一对对齐输入：干净图与随机合成漂移图。漂移类型从
`bright,dark,blur,noise,occlusion` 独立采样，避免旧时间 schedule 将漂移类型与数据顺序绑定。
训练损失为：

```text
L = L_cls(drift, label)
  + 0.25 * L_feature(drift CLS, frozen clean CLS)
  + 0.20 * L_consistency(drift logits, frozen clean logits)
```

其中干净侧 MV-ViT + Adapter 关闭，作为冻结参考；漂移侧开启 Adapter 并接收梯度。
主干参数冻结，训练参数为 299,916 个，最终下发 checkpoint 约 1.2 MB，保持现有小参数包格式。

## a3 执行记录

- 设备：a3，NVIDIA GeForce RTX 3090 24 GB，单卡。
- 数据：`/root/autodl-tmp/EdgeCloudRuntime/shared/data/BoxCars116k_kaggle/BoxCars116k`。
- baseline：`checkpoints/boxcars_make_baseline/best.pth`。
- 训练集：13,098 个样本；验证集：649 个样本。
- 训练配置：8 epochs，batch size 4，梯度累积 2，AdamW，学习率 `2e-4`，权重衰减 `0.05`，bf16。
- 代码：同步本地 `adjust` 工作区中的漂移数据集、训练/评估脚本、模型和 README 到 a3；没有覆盖远端 `second` 分支的无关未提交修改。

训练启动时发现：单卡使用 `torchrun` 时仍会创建 DDP；由于干净参考分支关闭 Adapter，DDP 会将
部分参数误判为未参与某次反向。已在
`module_edge_perception/train_boxcars_drift_adapter.py` 中启用
`find_unused_parameters=True`，随后训练正常完成。这是并行训练兼容性修复，不改变损失定义。

最佳验证 checkpoint 出现在 epoch 2（epoch 6 同分）：漂移准确率 93.07%，干净准确率 94.30%。
最终统一评估加载的是该 `best.pth`，而非最后一个 epoch 的 `latest.pth`。

## 统一评估结果

评估严格使用相同设置：`validation` split、649 个样本、随机种子 123、severity=0.8；baseline 与
`general` Adapter 对每一类漂移使用同一组样本及同一合成随机性。

| 输入域 | Baseline Top-1 | General Top-1 | 变化 |
|---|---:|---:|---:|
| clean | 93.84% | 94.30% | +0.46 pp |
| bright | 91.99% | 92.76% | +0.77 pp |
| dark | 93.84% | 94.14% | +0.31 pp |
| blur | 92.30% | 93.37% | +1.08 pp |
| noise | 92.30% | 93.37% | +1.08 pp |
| occlusion | 91.83% | 92.14% | +0.31 pp |

所有域均为正增益，且干净域没有回退。收益最大的是 blur/noise（均为 +1.08 pp）；在本实验强度下，
各类 baseline 下降本身较小，因此增益也处于温和范围。结果支持先部署或继续验证统一 Adapter，
但不足以证明专家 bank 的维护成本合理。

## 后续建议

1. 将 severity 扩展为多个档位，并至少增加 test split，确认收益不只来自单一验证强度。
2. 仅在 blur/noise 的多强度评估中仍持续显著领先 `general` 时，再训练对应专家；否则不维护 Adapter bank。
3. 为 `view_failure` 或按视图质量分桶的样本增加评估，单独验证方案所说的坏视图抑制能力。
4. 在合成 oracle 结果稳定后，再评估 VLM 的受约束退化标签能否可靠地选择 Adapter；VLM 不参与品牌类别监督。
