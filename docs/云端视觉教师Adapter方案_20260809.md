# 云端视觉教师指导的 Adapter 刷新方案

> 状态：当前正式方案（2026-08-09）。本文覆盖旧的 VLM-conditioned Adapter 叙事；旧实现和实验记录只保留为消融证据。

## 结论

Adapter 对 BoxCars 相机漂移有效，但 Qwen3-VL 对 drift correction 没有可靠增益。原因不是 Adapter 失效，而是把擅长高层语义与语言推理的 VLM，错误地用作 illumination、motion blur、sensor noise 等**低层协变量漂移**的控制器。

因此，新方案不让大模型进入边缘 forward，也不让 VLM 的 128D condition / FiLM 控制 Adapter。云端冻结的大型**视觉**基础模型负责产生适配监督；AdaptFormer 负责把该监督压缩成约 1.2 MB 的边缘更新包。

```text
漂移检测
  -> 上传少量 representative / hard 四视图轨迹
  -> 云端冻结视觉教师提取 task logits + visual features
  -> 云端仅训练 MV-ViT-S 的 AdaptFormer
  -> 下发 adapter-only checkpoint
  -> 边缘 MV-ViT-S + Adapter 低延迟恢复推理
```

当前优先验证的 cloud teacher 是 `OpenGVLab/InternViT-6B-224px`：5.903B 参数、224 输入、视觉 feature backbone。它在单张 RTX 3090 上只作 BF16 / batch=1 的离线特征提取；不训练、不部署到边缘。DINOv3 仍是低层 OOD 鲁棒性的重要对照，但 7B checkpoint 不适合当前仅剩约 30GB 磁盘的服务器环境。

## 新旧方案对比

| 项目 | 旧：VLM-conditioned Adapter（否定的消融） | 新：Cloud visual teacher-guided Adapter refresh（正式方案） |
|---|---|---|
| 云端模型职责 | Qwen3-VL 生成语义 condition，直接调制 edge Adapter | 大型视觉 backbone 为漂移样本产生 logits / features 监督 |
| 大模型是否进入 edge forward | 是，edge condition / FiLM 与 VLM cache 强耦合 | 否；边缘前向只有 MV-ViT-S + AdaptFormer |
| 迁移对象 | VLM 语义 hidden state 或品牌 logits | 任务对齐的视觉特征与 cloud classifier logits |
| 对低层漂移的假设 | 语义表征可直接说明 blur / illumination / noise 的修正方式 | 强视觉表征更适合提供退化域下的判别监督 |
| 训练产物 | 条件控制器 + FiLM Adapter + 质量头 | Adapter-only checkpoint；训练期 projector 不下发 |
| 部署依赖 | 可能依赖 VLM condition 或 edge condition predictor | 不依赖云端实时返回；只在 u=1 更新时使用云端 |
| 实验定位 | 已验证为无明显贡献或负增益的消融 | 待以 Clean / Illumination / Blur / Noise 表正式验证 |

Qwen3-VL 仍可保留给调度器：例如判断摄像头迁移、场景结构变化或辅助选择 `u=0/1/2`。它不再承担像素级/相机链路退化校正的教师角色。

## 云端训练目标

对同一轨迹的漂移输入 \(x_d\)，云端视觉教师输出任务 logits \(z_T\) 与视觉特征 \(h_T\)；开启 Adapter 的边缘学生输出 \(z_S,h_S\)。关闭 Adapter 的冻结 baseline 对 clean replay 输出 \(z_0\)。

\[
L = L_{CE}(z_S,y)
  + \lambda_{KD} KL_T(z_S,z_T)
  + \lambda_f[1-\cos(P(h_S), h_T)]
  + \lambda_a KL_T(z_S,z_0)
\]

- `CE`：保持真实 BoxCars 标签监督，避免 teacher 在细粒度品牌上出错时主导训练。
- `KD`：迁移 cloud teacher 在漂移样本上的 task-specific 判别分布。
- `feature alignment`：通过只在云端训练的投影器 `P` 对齐视觉表征；`P` 不进入 adapter checkpoint。
- `anchor`：clean replay 防止 Adapter 只适应当前漂移而损伤原始能力。

prototype head 只用于五分钟零训练 sanity check，不作为正式 teacher。正式 logits 必须来自冻结 InternViT feature 上训练的 BoxCars linear/小 MLP head，训练数据使用 clean + illumination / blur / noise 混合，并在独立 validation drift 上准入验证。

## 实现与运行流程

新增的正式代码入口如下：

1. `module_edge_perception/export_boxcars_cloud_teacher_cache.py`
   - 加载冻结 InternViT；对 clean / drifted 四视图提取并池化 feature；
   - 加载已训练的 BoxCars linear/MLP head；
   - 按数据集索引输出 `train` 与 `validation` 的 `{features, logits}` cache。
2. `module_edge_perception/train_boxcars_cloud_teacher_adapter.py`
   - 加载冻结 MV-ViT baseline；挂无条件 `AdaptFormer(condition_dim=0)`；
   - 读取 cloud cache，按上述目标训练；
   - 保存 adapter-only `best.pth`，与既有 u=1 下发接口兼容。

典型命令（a4）：

```bash
python module_edge_perception/export_boxcars_cloud_teacher_cache.py \
  --dataset-path data/BoxCars116k_kaggle/BoxCars116k \
  --model-path models/shared/InternViT-6B-224px \
  --head-checkpoint outputs/internvit6b_boxcars_noise_head_20260809/selected_head.pt \
  --output outputs/internvit6b_boxcars_teacher_cache.pth

python module_edge_perception/train_boxcars_cloud_teacher_adapter.py \
  --dataset-path data/BoxCars116k_kaggle \
  --baseline-checkpoint checkpoints/shared/boxcars_make_baseline/best.pth \
  --teacher-cache outputs/internvit6b_boxcars_teacher_cache.pth \
  --expert-name internvit6b_cloud_teacher
```

## 调度器与接口含义

| 动作 | 新定义 |
|---|---|
| `u=0` | 当前 Adapter 足够，边缘本地自治。 |
| `u=1` | Cloud teacher-guided Adapter refresh：上传代表性漂移样本，云端生成监督并更新约 0.3M 参数，向边缘下发约 1.2MB。 |
| `u=2` | 结构性漂移或任务变化，更新主干/分类头等更大范围模型。 |

`u=1` 的上行样本和下行 Adapter 与既有通信预算兼容；教师权重、cache 和训练期 projector 永远留在云端。

## 验收实验

不能只报告 Adapter 相比 baseline 的提升。至少同一 split、同一 corruption seed 下报告：

| Model | Clean | Illumination | Motion blur | Sensor noise |
|---|---:|---:|---:|---:|
| Edge MV-ViT-S | 93.84% | 81.82% | 84.59% | 79.51% |
| Edge + label-only Adapter | 94.30% | 83.05% | 87.52% | 87.67% |
| Edge + cloud-teacher Adapter（无上传标签） | 94.61% | 83.05% | 86.13% | 86.44% |
| Cloud visual teacher | 96.15% | 94.92% | 91.99% | 82.59% |
| Qwen3-VL（旧消融） | 62.25% | | | |

只有 cloud visual teacher 在漂移域确实比边缘 baseline 稳健，且其指导 Adapter 进一步改善 edge 结果时，才能宣称云端大模型协同对漂移校正有效。若 InternViT-6B 不满足第一项，应回到 DINOv3 H+/L 或训练 domain-specific ViT-L teacher，而不是恢复 VLM condition 路线。

本轮使用每 epoch 约 1,024 条代表性 train tracks、4 epoch、完整 validation 的结果表明：

- cloud-unlabeled Adapter 三漂移平均为 85.21%，较未适配 Edge 的 81.97% 提升 3.24 pp；
- 它距有标签 label-only 上界 86.08% 仅 0.87 pp，且 clean 与三种漂移均未退化；
- cloud hybrid 为 85.67%，比 label-only 低 0.41 pp，因此“在已有真实标签 CE 上叠加当前 KD/feature”不构成额外增益。

正式系统结论应是：云端 teacher 在无上传标签时替代人工标注产生适配监督，而不是声称它在有标签训练上必然超过 CE。Hybrid 结果保留为消融。

### 快速独立 test check（不是全量 test 终稿）

为确认上述开发集结论没有只在 validation 成立，固定已有 checkpoint 后，在官方 `test` split 上进行了
一个 256 条的 deterministic class-stratified check。官方 test 共 12,322 条且类别极不均衡，最稀有
类别 Porsche 仅 3 条；该检查保证每类至少一条，其余按官方类别容量分配，因而适合快速方向确认，
不适合按类别或最终统计口径作强结论。

| Model | Clean | Illumination | Blur | Noise | Mean drift |
|---|---:|---:|---:|---:|---:|
| Edge baseline | 85.55% | 74.61% | 73.83% | 69.92% | 72.79% |
| Edge + cloud-unlabeled Adapter | **87.50%** | **76.17%** | **74.22%** | **77.73%** | **76.04%** |
| Cloud visual teacher | 92.97% | 91.41% | 91.02% | 80.86% | 87.76% |

cloud-unlabeled 的平均漂移提升为 **+3.26 pp**，与开发集 +3.24 pp 同方向。逐条件的 paired bootstrap
显示 noise 差异为 +7.81 pp，95% CI `[+3.91, +11.72] pp`；illumination/blur 的小提升在 256 条
快速样本上尚不足以给出不跨 0 的区间。故这组 test 结果支持路线保留，但不把它夸大为全量 test 的最终
显著性结论。评估器会保存 sample indices 与逐样本 prediction，见
`module_edge_perception/evaluate_boxcars_cloud_teacher_quick_test.py`。

# 结果
已经全部完成，主系统 gate 为 **PASS**。

| Model | Clean | Illumination | Blur | Noise | Mean drift |
|---|---:|---:|---:|---:|---:|
| Edge baseline | 93.84% | 81.82% | 84.59% | 79.51% | 81.97% |
| Cloud teacher | 96.15% | 94.92% | 91.99% | 82.59% | 89.83% |
| Label-only Adapter | 94.30% | 83.05% | 87.52% | 87.67% | 86.08% |
| Cloud hybrid Adapter | 94.30% | 83.36% | 86.75% | 86.90% | 85.67% |
| Cloud unlabeled Adapter | **94.61%** | **83.05%** | **86.13%** | **86.44%** | **85.21%** |

核心结论：

- Cloud-unlabeled 完全不使用上传样本真实标签，平均漂移准确率比 Edge 高 **3.24 pp**。
- 它只比有标签 label-only 上界低 **0.87 pp**。
- Clean 保持，并且 illumination、blur、noise 分别提升 **1.23、1.54、6.93 pp**。
- Hybrid 比 label-only 低 0.41 pp，所以不能宣称 cloud teacher 在已有标签 CE 上还有额外增益；它的价值是替代真实环境中缺失的人工标签。
- 当前不需要切换 DINOv3，也没有必要为了 hybrid 指标盲目调参。
- 快速独立 test 与开发集方向一致；当前可以接入 `u=1` demo，不需要先做大规模补充实验。

下发包已经验证：

- 299,916 个 AdaptFormer 参数
- 1,216,745 bytes，约 1.2MB
- 不包含 backbone、norm、head 或 cloud projector
- 三个 checkpoint 均通过键和参数量审计
