# 云端实验运行目录约定

云端 GPU 环境用于训练和完整评测，不承担 Git 工作区内的大文件存储。推荐使用以下可移植布局：

```text
EdgeCloudRuntime/
├── source/                    # 固定 Git commit 的代码副本
├── data/                      # ModelNet40、BoxCars116k
├── models/                    # 基座模型、baseline、正式 Adapter
├── runs/
│   └── <experiment-id>/
│       ├── config.json
│       ├── outputs/
│       ├── logs/
│       ├── checkpoints/
│       └── manifest.sha256
└── delivery/                  # 精简后的正式证据
```

## 约束

- 每次实验记录 Git commit、命令、随机种子、硬件和依赖版本。
- 代码通过命令行参数接收数据、模型和输出路径，不写入服务器专用绝对路径。
- 日志、中间 cache 和候选 checkpoint 写入独立实验目录，不覆盖正式证据。
- `data/` 与基础 `models/` 只读共享；最终 Adapter 经过校验后复制到正式交付目录。
- 回传 Git 仓库的 `artifacts/` 只包含必要 CSV、JSON、日志摘要、配置和绘图数据。
- 大型数据、基座模型和完整预测明细通过 GitHub Release 或赛事提交包清单交付。

公开复现命令统一维护在根目录 [REPRODUCE.md](../REPRODUCE.md)，不在本文记录个人服务器名称或工作树路径。
