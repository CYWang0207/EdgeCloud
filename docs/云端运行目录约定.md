# a4 云端运行目录约定

`a4:/root/autodl-tmp/EdgeCloudRuntime` 不承担 Git 提交，只作为分支隔离的运行环境。

```text
EdgeCloudRuntime/
├── worktrees/
│   ├── adjust/       # InternViT cloud teacher / Adapter 实验
│   │   ├── outputs/
│   │   ├── logs/
│   │   ├── checkpoints/
│   │   └── archive/
│   └── second/       # second 分支运行副本
│       ├── outputs/
│       ├── logs/
│       ├── checkpoints/
│       └── archive/
└── shared/
    ├── data/          # 唯一共享数据集区
    ├── models/        # 唯一共享基础模型权重区
    └── checkpoints/   # 可跨分支复用的 baseline/下发权重
```

约束：

- 实验输出、日志、中间 cache 和历史归档必须写入当前分支目录，不得写入 `shared/`。
- `adjust/data/shared`、`adjust/models/shared`、`adjust/checkpoints/shared` 及 `second` 中的同名入口只是共享资产链接。
- 运行 adjust 任务前：`cd /root/autodl-tmp/EdgeCloudRuntime/worktrees/adjust`。
- 运行 second 任务前：`cd /root/autodl-tmp/EdgeCloudRuntime/worktrees/second`。
- 命令必须显式把 `--output` / `--save-dir` 指向当前 worktree 的 `outputs/` 或 `checkpoints/`。
