# 多场景漂移校正 Adapter 实验总览（2026-08-06）

本记录取代旧的仅 BoxCars 合成漂移实验记录，汇总当前两个场景使用“先校准、再训练、后逐类评测”的结果。

## ModelNet40

数据集为 9,843 train / 2,468 test，四个规整渲染视图；基座为
`mv_vit_token_epoch_30.pth`。完整 test 集校准后，三类退化造成 7.58、7.62、12.16pp
下降。训练 8 epochs 的 camera-mixture adapter 后：

| 条件 | Baseline | Adapter | 变化 |
|---|---:|---:|---:|
| clean | 96.76% | 96.47% | -0.28pp |
| illumination=1.0 | 89.18% | 95.14% | +5.96pp |
| defocus=0.2 | 89.14% | 96.43% | +7.29pp |
| sensor-noise=0.4 | 84.60% | 95.66% | +11.06pp |

权重：`shared/checkpoints/modelnet40_drift_adapters/camera_mixture_calibrated/best.pth`。
完整记录见 [ModelNet40 Adapter 相机退化实验](ModelNet40_Adapter相机退化实验_20260806.md)。

## BoxCars116k：重新校准的监控相机退化

旧 BoxCars `general` 使用全局亮暗、Gaussian blur/white noise 等简化干预，在
`severity=0.8` 下通常只造成 0–2pp 下降，不能作为有说服力的鲁棒性训练域。本次没有
修改该实现或覆盖旧权重，而是新增 `boxcars_camera_drift_dataset.py` 与独立训练、校准、
评测脚本。

### 校准

设备为 a3 NVIDIA RTX 3090；BoxCars `make` validation=649，clean baseline=93.84%。
以下是进入训练的固定档位：

| 退化 | 监控语义 | 固定 severity | Baseline | 相对 clean 下降 |
|---|---|---:|---:|---:|
| illumination | 夜间/逆光、色温、局部阴影 | 1.0 | 81.82% | 12.02pp |
| motion blur | 车辆运动/快门方向模糊 | 0.8 | 84.59% | 9.24pp |
| sensor noise | 低照度 ISO/gain 的 Poisson-Gaussian | 0.6 | 79.51% | 14.33pp |
| haze | 雾霾大气散射 | 1.0 | 86.90% | 6.93pp |

`compression`、单帧 `partial_occlusion`、`glare` 和 `lens_obstruction` 在当前四视图
融合模型上仅造成约 0–2.3pp 下降，未进入训练。它们不是“不真实”，而是该数据及模型
的多视图冗余足以抵消它们；把它们等权混入会稀释有意义的校正目标。

### 训练与完整对比

训练集 13,098，8 epochs，batch size 8，r=32，四类权重为
`0.25 / 0.25 / 0.30 / 0.20`，clean 概率 20%。最佳 checkpoint 出现在 epoch 6，
其混合 validation 为 90.91%。下表以同一 validation 全集、同一随机种子和固定退化
比较冻结 baseline 与该 `best.pth`：

| 条件 | Baseline | Camera-mixture Adapter | 变化 |
|---|---:|---:|---:|
| clean | 93.84% | 94.14% | +0.31pp |
| illumination=1.0 | 81.82% | 88.60% | +6.78pp |
| motion-blur=0.8 | 84.59% | 89.98% | +5.39pp |
| sensor-noise=0.6 | 79.51% | 91.06% | +11.56pp |
| haze=1.0 | 86.90% | 93.37% | +6.47pp |

结果说明场景专用的混合 adapter 能恢复所有已校准监控退化，同时 clean 域未回退。
