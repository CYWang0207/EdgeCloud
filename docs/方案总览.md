# 方案总览：面向端边云协同推理的分布式感知与全局优化决策系统

## 赛题理解

赛题要求构建一套"分布式感知 + 云边协同推理 + 全局优化决策"系统。我们的核心判断是：**不把 DeepSeek 蒸馏成小模型部署到边缘，而是让 DeepSeek 在云端当"军师"，把场景理解压缩成 Prompt Token 注入边缘 ViT。**

## 系统闭环

```
感知（边缘 ViT 多视角推理）
  -> 漂移检测（香农熵 Edrift）
  -> 调度（Actor-Critic 在线决策 {vt, ut, kt}）
  -> 协同（ut != 0 时触发云端下发 Prompt/重训权重）
  -> 云端持续学习 + 多节点仲裁
  -> 回到感知
```

## 模块划分

### 模块一：边缘实时感知（module_edge_perception）
- MV-ViT 多视角推理（ViT-Small，2200万参数）
- Token 剪枝：动态保留率 k_t，降低 Self-Attention 复杂度
- 漂移模拟：5种环境漂移（变亮/暗/模糊/噪声/遮挡）
- Prompt 生成：云端下发 4 个 Prompt Token 注入 ViT 序列
- 性能测量：TTFT、推理延迟、GPU 内存

### 模块二：云边协同调度（module_scheduling）
- Actor-Critic RL：Actor（DNN）生成候选动作，Critic（注水算法）精确评估
- Lyapunov 带宽队列：长期平均带宽约束
- VLM Oracle：模拟 DeepSeek 的场景分析行为
- 多节点协同：冲突检测（<5%）+ 一致性仲裁（>90%）
- 网络韧性：带宽波动 + 断连 fallback

## 知识压缩方案（答辩核心）

传统思路：DeepSeek(1750亿) -> 剪枝/量化/蒸馏 -> 迷你DeepSeek(1000万) -> 边缘部署
我们的思路：DeepSeek(1750亿) 在云端 -> 分析场景 -> 输出Prompt Token(2KB) -> 注入边缘ViT

**压缩的不是参数，是知识。传输的不是模型，是场景理解。**

## 技术指标达成路径

| 指标 | 如何达成 |
|------|---------|
| 边侧参数量千万级 | ViT-Small（2200万）天然满足 |
| TTFT降低 >= 75% | Token 剪枝：序列长度从785 -> 200，Attention O(N^2) 降低90%+ |
| 内存 <= 1.5GB | ViT-Small + Token剪枝约1GB |
| 端到端 <= 0.2s | 视角休眠 + Token剪枝 + 注水算法O(V^2) |
| 业务连续性 >= 90% | Lyapunov 稳定性 + ut=0 本地自治 |
| 冲突 <= 5%，解决 >= 90% | 云端 VLM 全局仲裁 + 置信度加权投票 |
| >= 2类场景 | ModelNet40 + 智慧交通/工业检测 |
