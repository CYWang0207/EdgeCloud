# 接口契约 v2（两模块简化版）

> 2026-08-03 起 u=1 语义由"Prompt 同步"改为"AdaptFormer adapter 参数同步"；2026-08-04 补充精确通信开销数值与下发物格式。下方为 Adapter 方案口径；prompt 注入为遗留可选辅助。

## 通信常量

| 常量 | 值 | 说明 |
|------|-----|------|
| S_adapter | **1.2 MB** | adapter 参数包大小（0.300M 参 × 4B/param，实测 checkpoint 1.25MB） |
| S_query | **5.0 MB** | 边缘上传云端的关键帧数据量（4 视角 × 压缩后图像 + 元数据） |
| SCL_weights | **50 MB** | 网络模拟用的结构性大更新包；不是已验证 adapter-only checkpoint 的实物大小 |

## 协同动作 u_t 语义

| u_t | 含义 | 通信开销 c_comm | 治理对象 |
|-----|------|----------------|----------|
| 0 | 本地自治（冻结主干+adapter 直接推理） | **0** | 离线/弱网可用 |
| 1 | adapter 参数同步（云端下发 adapter 权重，约 1.2 MB） | S_adapter + S_query ≈ **6.2 MB** | 环境漂移 |
| 2 | 结构性大更新同步（网络模拟） | SCL_weights + S_query ≈ **55 MB** | 结构性漂移 |

### adapter 下发物说明

u=1 云端下发的是场景专用 adapter-only 权重，**不是整个模型**。格式为 `{"adapter": {...}}`（其中含 adapter、norm、head），约 1.2–1.3 MB。MV-ViT 主干（22M 参 ≈ 90MB）冻结在边缘不动，不下发；该权重来自已校准相机退化上的成对训练。

## 接口1：边缘感知 -> 调度器

| 项 | 内容 | 格式 |
|----|------|------|
| Edrift(t) | 当前漂移估计（香农熵） | float |
| struct_drift | 结构漂移分数 | float |
| 推理延迟 | 当前模型单帧耗时 | ms |

## 接口2：调度器 -> 边缘感知

| 项 | 内容 | 格式 |
|----|------|------|
| v_t | 视角选择 | [0,1,1,0] |
| k_t | Token 保留率 | [0.7, 0.3, 0.8, 0.0] |
| u_t | 协同模式 | 0/1/2（见上表） |

## 接口3：场景校准与 Adapter 产出

| 项 | 内容 | 格式 |
|----|------|------|
| 输入 | 场景数据、相机退化配置、baseline checkpoint | dataset + config + checkpoint |
| 输出 | 场景专用 adapter-only checkpoint 与校准记录 | `.pth` + JSON |
| 约束 | 权重按数据域与退化配置隔离，不跨场景复用 | metadata |

## 接口4：多节点仲裁

| 项 | 内容 | 格式 |
|----|------|------|
| 节点上报 | 节点ID + 预测结果 + 置信度 | JSON |
| 仲裁下发 | 一致化决策 + 生效时序 | JSON |
| 边侧回滚 | 冲突触发回滚条件 | 阈值配置 |

## 修改流程

1. 提交 PR 修改本文档对应小节
2. 接口相关方评审通过后合并
3. 对应代码同步更新
