# 接口契约 v2（两模块简化版）

> 2026-08-03 起 u=1 语义由"Prompt 同步"改为"AdaptFormer adapter 参数同步"；2026-08-09 切换为 cloud-teacher 方案：云端冻结 InternViT-6B → 训练 AdaptFormer → 下发约 1.2MB adapter-only checkpoint。方法设计与实验总览见[实验结果总览](实验结果总览_20260809.md)，历史方案仅作归档背景，正式证据见 `../artifacts/`。

## 通信常量

| 常量 | 值 | 说明 |
|------|-----|------|
| S_adapter | **1.2 MB** | 纯 AdaptFormer 参数包（299,916 参数；BoxCars 1,216,745 bytes / ModelNet40 1,219,859 bytes，不含 backbone/norm/head/projector） |
| S_query | **5 MB** | 边缘上传漂移样本的数据量（4 视角压缩图像 + 元数据），总量取决于每次 refresh 的样本数；网络模拟参数 |
| SCL_weights | **50 MB** | u=2 模式下主干或分类头更新的通信开销；网络模拟参数 |

## 协同动作 u_t 语义

| u_t | 含义 | 通信开销 c_comm | 治理对象 |
|-----|------|----------------|----------|
| 0 | 本地自治（冻结主干+adapter 直接推理，断网时回退） | **0** | 离线/弱网可用 |
| 1 | cloud-teacher adapter refresh：上传漂移样本 → 云端 InternViT-6B 提取 {features, logits} → 四目标蒸馏训练约 0.3M 参数 → 下发约 1.2 MB adapter | 下行 S_adapter ≈ 1.2 MB + 上行 S_query ≈ 5 MB（4 视角图像 + 元数据） | 环境漂移 |
| 2 | 结构性漂移/任务变化，更新主干或分类头等更大范围模型，异步后台进 Q_net 跨槽消化 | SCL_weights + S_query（50 MB + 5 MB） | 结构性漂移 |

### adapter 下发物说明

u=1 云端下发的是纯 AdaptFormer 权重，**不是整个模型**。格式为 `{"adapter": {...}}`，约 1.2 MB（299,916 参数，1,216,745 bytes，不含 backbone、norm、head、cloud projector）。MV-ViT 主干（22M 参 ≈ 90MB）冻结在边缘不动，不下发。该权重来自云端 InternViT-6B 教师蒸馏，cloud-unlabeled 口径下不使用上传样本真实标签（λ_CE=0）。InternViT-6B、task head、Teacher Cache、训练期 projector 永远留在云端，不进入边缘 forward。

## 接口1：边缘感知 -> 调度器

| 项 | 内容 | 格式 |
|----|------|------|
| Edrift(t) | 当前漂移估计（香农熵） | float |
| struct_drift | 结构漂移分数 | float |
| 推理延迟 | 当前模型单帧耗时 | ms |

## 接口2：调度器 -> 边缘感知

| 项 | 内容 | 格式 |
|----|------|------|
| v_t | 视角选择 | [0,1,1,0] |
| k_t | Token 保留率 | [0.7, 0.3, 0.8, 0.0] |
| u_t | 协同模式 | 0/1/2（见上表） |

## 接口3：云端教师缓存与 Adapter 产出

| 项 | 内容 | 格式 |
|----|------|------|
| 输入 | 漂移样本（无标签）、baseline checkpoint、Teacher Cache（InternViT-6B 离线提取的 features + logits） | dataset + checkpoint + cache |
| 输出 | 纯 AdaptFormer checkpoint（不含 backbone/norm/head/projector） | `.pth` |
| 约束 | 两场景权重隔离，不跨场景复用；cloud-unlabeled 口径 λ_CE=0；Teacher Cache 一次提取、多次复用 | metadata |

## 接口4：多节点仲裁

| 项 | 内容 | 格式 |
|----|------|------|
| 节点上报 | 节点ID + 预测结果 + 置信度 | JSON |
| 仲裁下发 | 一致化决策 + 生效时序 | JSON |
| 边侧回滚 | 冲突触发回滚条件 | 阈值配置 |
