# 接口契约 v2（两模块简化版）

> 2026-08-03 起 u=1 语义由"Prompt 同步"改为"AdaptFormer adapter 参数同步"；2026-08-09 起，u=1 的云端监督正式改为**冻结视觉基础模型产生的 logits/features**，不再由 VLM condition 或 VLM 品牌 soft labels 直接控制 edge Adapter。完整设计见[云端视觉教师 Adapter 刷新方案](云端视觉教师Adapter方案_20260809.md)。

## 通信常量

| 常量 | 值 | 说明 |
|------|-----|------|
| S_adapter | **1.2 MB** | adapter 参数包大小（299,916 参；实测 checkpoint 1,216,745 bytes） |
| S_query | **5.0 MB** | 边缘上传云端的关键帧数据量（4 视角 × 压缩后图像 + 元数据） |
| SCL_weights | **50 MB** | 云端重训后的 adapter 全量权重包（u=2 下发） |

## 协同动作 u_t 语义

| u_t | 含义 | 通信开销 c_comm | 治理对象 |
|-----|------|----------------|----------|
| 0 | 本地自治（冻结主干+adapter 直接推理） | **0** | 离线/弱网可用 |
| 1 | cloud teacher-guided adapter refresh（云端下发 adapter 权重，约 1.2 MB） | S_adapter + S_query ≈ **6.2 MB** | 环境漂移 |
| 2 | 结构性模型更新（必要时更新主干/分类头等较大组件，约 50 MB） | SCL_weights + S_query ≈ **55 MB** | 结构性漂移 |

### adapter 下发物说明

u=1 云端下发的是 adapter 增量权重，**不是整个模型**。当前正式 checkpoint 格式为
`{"adapter": {...}, ...metadata}`，其中只含各 Transformer block 的 AdaptFormer 参数和 scale；
不含 backbone、`norm`、`head`、InternViT 或训练期 projector。实测大小为 1,216,745 bytes。
MV-ViT 主干（约 22M 参数）冻结在边缘不动，不下发——压缩的不是参数，是云端大模型蒸馏出来的场景知识；传输的是这个小适配器。

## 接口1：边缘感知 -> 调度器

| 项 | 内容 | 格式 |
|----|------|------|
| Edrift(t) | 当前漂移估计（香农熵） | float |
| struct_drift | 结构漂移分数 | float |
| 推理延迟 | 当前模型单帧耗时 | ms |

## 接口2：调度器 -> 边缘感知

| 项 | 内容 | 格式 |
|----|------|------|
| v_t | 视角选择 | [0,1,1,0] |
| k_t | Token 保留率 | [0.7, 0.3, 0.8, 0.0] |
| u_t | 协同模式 | 0/1/2（见上表） |

## 接口3：Cloud Visual Teacher

| 项 | 内容 | 格式 |
|----|------|------|
| 输入 | representative / hard 多视图轨迹 | image + metadata |
| 输出视觉监督 | task logits + visual features（仅云端 cache 使用） | tensors |
| 输出下发物 | 训练后的 adapter-only checkpoint | `{"adapter": ...}` |

## 接口4：多节点仲裁

| 项 | 内容 | 格式 |
|----|------|------|
| 节点上报 | 节点ID + 预测结果 + 置信度 | JSON |
| 仲裁下发 | 一致化决策 + 生效时序 | JSON |
| 边侧回滚 | 冲突触发回滚条件 | 阈值配置 |

## 修改流程

1. 提交 PR 修改本文档对应小节
2. 接口相关方评审通过后合并
3. 对应代码同步更新
