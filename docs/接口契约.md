# 接口契约（两模块简化版）

> 2026-08-03 起 u=1 语义由"Prompt 同步"改为"AdaptFormer adapter 参数同步"。下方为 Adapter 方案口径；prompt 注入为遗留可选辅助。

## 协同动作 u_t 语义

| u_t | 含义 | 通信开销 c_comm | 治理对象 |
|-----|------|----------------|----------|
| 0 | 本地自治（冻结主干+adapter 直接推理） | 0 | 离线/弱网可用 |
| 1 | adapter 参数同步（云端下发 adapter 权重，几百KB~MB） | S_adapter + S_query | 环境漂移 |
| 2 | 重训权重同步（云端下发重训 adapter，~50MB） | SCL_weights + S_query | 结构性漂移 |

## 接口1：边缘感知 -> 调度器

| 项 | 内容 | 格式 |
|----|------|------|
| Edrift(t) | 当前漂移估计（香农熵） | float |
| struct_drift | 结构漂移分数 | float |
| 推理延迟 | 当前模型单帧耗时 | ms |

## 接口2：调度器 -> 边缘感知

| 项 | 内容 | 格式 |
|----|------|------|
| v_t | 视角选择 | [0,1,1,0] |
| k_t | Token 保留率 | [0.7, 0.3, 0.8, 0.0] |
| u_t | 协同模式 | 0/1/2（见上表） |

## 接口3：VLM Oracle

| 项 | 内容 | 格式 |
|----|------|------|
| 输入 | 关键帧 + 漂移类型 | image + str |
| 输出 软标签 | 蒸馏监督 adapter 的软标签/知识 | logits/probs |
| 输出 w_t | 空间权重 | [w1,w2,w3,w4] |

## 接口4：多节点仲裁

| 项 | 内容 | 格式 |
|----|------|------|
| 节点上报 | 节点ID + 预测结果 + 置信度 | JSON |
| 仲裁下发 | 一致化决策 + 生效时序 | JSON |
| 边侧回滚 | 冲突触发回滚条件 | 阈值配置 |

## 修改流程

1. 提交 PR 修改本文档对应小节
2. 接口相关方评审通过后合并
3. 对应代码同步更新
