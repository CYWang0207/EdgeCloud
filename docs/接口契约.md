# 接口契约 v2（两模块简化版）

> 2026-08-03 起 u=1 语义由"Prompt 同步"改为"AdaptFormer adapter 参数同步"；2026-08-04 补充精确通信开销数值与下发物格式。下方为 Adapter 方案口径；prompt 注入为遗留可选辅助。

## 通信常量

| 常量 | 值 | 说明 |
|------|-----|------|
| S_adapter | **1.2 MB** | adapter 参数包大小（0.300M 参 × 4B/param，实测 checkpoint 1.25MB） |
| S_query | **5.0 MB** | 边缘上传云端的关键帧数据量（4 视角 × 压缩后图像 + 元数据） |
| SCL_weights | **50 MB** | 云端重训后的 adapter 全量权重包（u=2 下发） |

## 协同动作 u_t 语义

| u_t | 含义 | 通信开销 c_comm | 治理对象 |
|-----|------|----------------|----------|
| 0 | 本地自治（冻结主干+adapter 直接推理） | **0** | 离线/弱网可用 |
| 1 | adapter 参数同步（云端下发 adapter 权重，约 1.2 MB） | S_adapter + S_query ≈ **6.2 MB** | 环境漂移 |
| 2 | 重训权重同步（云端下发重训 adapter 权重，约 50 MB） | SCL_weights + S_query ≈ **55 MB** | 结构性漂移 |

### adapter 下发物说明

u=1 云端下发的是 adapter 增量权重，**不是整个模型**。格式为 `{"adapter": {...}, "norm": {...}, "head": {...}}`，约 1.2 MB（0.300M 可训参）。MV-ViT 主干（22M 参 ≈ 90MB）冻结在边缘不动，不下发——压缩的不是参数，是云端大模型蒸馏出来的场景知识；传输的不是模型，是压缩后的小适配器。

## 接口1：边缘感知 -> 调度器

| 项 | 内容 | 格式 |
|----|------|------|
| Edrift(t) | 当前漂移估计（香农熵） | float |
| struct_drift | 结构漂移分数 | float |
| 推理延迟 | 当前模型单帧耗时 | ms |

## 接口2：调度器 -> 边缘感知

| 项 | 内容 | 格式 |
|----|------|------|
| v_t | 视角选择 | [0,1,1,0] |
| k_t | Token 保留率 | [0.7, 0.3, 0.8, 0.0] |
| u_t | 协同模式 | 0/1/2（见上表） |

## 接口3：VLM Oracle

| 项 | 内容 | 格式 |
|----|------|------|
| 输入 | 关键帧 + 漂移类型 | image + str |
| 输出 软标签 | 蒸馏监督 adapter 的软标签/知识 | logits/probs |
| 输出 w_t | 空间权重 | [w1,w2,w3,w4] |

## 接口4：多节点仲裁

| 项 | 内容 | 格式 |
|----|------|------|
| 节点上报 | 节点ID + 预测结果 + 置信度 | JSON |
| 仲裁下发 | 一致化决策 + 生效时序 | JSON |
| 边侧回滚 | 冲突触发回滚条件 | 阈值配置 |
