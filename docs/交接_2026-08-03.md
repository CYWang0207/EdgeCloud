## 家里电脑跑 verify（不需要 GPU/数据集/权重，CPU 几秒）

verify 用 `pretrained=False` 随机权重，不要 N 卡、不下数据集、不下权重，纯 CPU 跑完。

### 1. 装 Python 3.11
从 https://www.python.org/downloads/ 下 **Python 3.11.x** 安装（务必勾选 "Add Python to PATH"）。不要用 3.14。

### 2. 装依赖（PowerShell）
```powershell
python -m pip install --upgrade pip
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
pip install timm
```
> 家里电脑若有 N 卡，把第二行换成 `pip install torch torchvision`（自动选 CUDA 版），其余不变；verify 仍走 CPU 也行。

### 3. 跑验收
```powershell
cd <项目解压路径>\module_edge_perception
python verify_adaptformer.py
```
预期 4 段输出全 ✅：① 零初始化输出差 <1e-3；② adapter 可训参 ~0.30M <1M；③ 三条前向路径；④ wrapper hook 触发。
