# 网络波动注入方案

## 目标

新增独立脚本 `module_scheduling/EdgeCloud_RL/network_sim.py`，用于模拟云边协同中的带宽抖动、丢包和断连，并给调度器提供统一 API。

当前只完成独立 API，不接入 `main_edge_cloud_new.py` 主循环。

## 核心 API

```python
from module_scheduling.EdgeCloud_RL.network_sim import NetworkSimulator

sim = NetworkSimulator(mode="markov", slot_duration=0.2, deadline_ms=200)
net = sim.step()
delay = sim.compute_e2e(u=1, realtime_comm=7.0)
queue = sim.update_queues(c_comm=7.0, u=1)
```

| API | 作用 |
|-----|------|
| `step()` | 采样当前网络状态，返回带宽、丢包率、容量和断连标记 |
| `filter_candidates(candidates, c_comm_map)` | 根据断连、强制本地和带宽约束过滤候选动作 |
| `compute_e2e(u, realtime_comm, t_edge=None)` | 计算通信时延、云端时延和端到端时延 |
| `update_queues(c_comm, b_avg=None, u=None)` | 更新 `Y_bw` 和 `Q_net`，处理 TTL / 队列上限 |
| `is_business_available(...)` | 判断当前时隙业务是否可用 |
| `business_continuity_rate(values)` | 计算业务连续性保持率 |

## 网络状态

| 字段 | 含义 |
|------|------|
| `network_state` | `STATIC` / `JITTER` / `GOOD` / `WEAK` / `DOWN` |
| `bandwidth_mbps` | 当前链路带宽，单位 Mbps |
| `loss_rate` | 当前时隙丢包率 |
| `effective_bandwidth_mbps` | 扣除丢包后的有效带宽 |
| `B_t` | 当前时隙可传输容量，单位 MB/slot |
| `disconnect_flag` | 是否断连 |

换算关系：

```text
effective_bandwidth_mbps = bandwidth_mbps * (1 - loss_rate)
B_t = effective_bandwidth_mbps * slot_duration / 8
```

除以 8 是因为 Mbps 使用 bit，MB 使用 Byte，1 Byte = 8 bit。

## 网络模式

| 模式 | 作用 |
|------|------|
| `static` | 固定带宽基线，等价于原 `b_avg` |
| `jitter` | 带宽随机抖动，不断连 |
| `jitter_outage` | 带宽抖动 + 随机/周期断连 |
| `markov` | GOOD / WEAK / DOWN 三状态弱网模型，推荐主实验使用 |

`markov` 默认转移矩阵：

```text
GOOD -> GOOD 0.92, WEAK 0.07, DOWN 0.01
WEAK -> GOOD 0.15, WEAK 0.75, DOWN 0.10
DOWN -> GOOD 0.30, WEAK 0.20, DOWN 0.50
```

## 动作定义

| 动作 | 含义 | 实时链路 | 进入 `Q_net` |
|------|------|----------|--------------|
| `u=0` | 本地自治 | 否 | 否 |
| `u=1` | 云端 Prompt 协同 | 是 | 否 |
| `u=2` | 模型权重同步/蒸馏更新 | 默认否 | 是 |

`u=2` 默认异步，不进入当前实时链路。若设置 `sync_u2=True`，则把 `u=2` 当作实时同步动作。

## 时延模型

```text
T_e2e = T_edge + T_comm + T_cloud
```

| 动作 | `T_cloud` |
|------|-----------|
| `u=0` | `0` |
| `u=1` | `prompt_cloud_delay_ms` |
| `u=2` 且 `sync_u2=False` | `0` |
| `u=2` 且 `sync_u2=True` | `retrain_cloud_delay_ms` |

默认 `deadline_ms=200`，对应赛题端到端时延不超过 0.2s。

## 队列保护

模拟器同时维护两个队列：

| 队列 | 含义 |
|------|------|
| `Y_bw` | 原 Lyapunov 长期平均通信预算队列 |
| `Q_net` | 网络传输积压队列，主要用于异步 `u=2` |

为防止慢性弱网下 `Q_net` 无限增长，新增：

| 参数 | 默认值 | 作用 |
|------|--------|------|
| `q_net_max` | 100 MB | 网络积压上限 |
| `queue_ttl_slots` | 50 | 异步任务最大保留时隙 |
| `queue_policy` | `drop_oldest` | 超限后丢弃最旧异步任务 |

可选 `queue_policy="force_local"` 或 `"hybrid"`，在队列过载时触发本地自治保护。

## 业务连续性

```text
business_available =
    decision_success
    and transmission_success
    and e2e_delay_ms <= deadline_ms
    and active_views >= business_min_active_views
    and proxy_acc >= acc_floor
```

验收指标：

```text
business_continuity_rate = mean(business_available)
business_continuity_rate >= 90%
```

该指标不是简单统计 `u=0` 次数，而是同时检查决策成功、传输成功、时延、视角数和代理精度。

## 推荐配置

```python
sim = NetworkSimulator(
    mode="markov",
    slot_duration=0.2,
    good_bandwidth_min_mbps=40,
    good_bandwidth_max_mbps=120,
    weak_bandwidth_min_mbps=2,
    weak_bandwidth_max_mbps=20,
    weak_loss_rate_min=0.05,
    weak_loss_rate_max=0.20,
    q_net_max=100.0,
    queue_ttl_slots=50,
    deadline_ms=200,
    seed=42,
)
```
