# 模块 C · 持续学习与全局决策（周老师组）

> 技术底座：云端 Replay Buffer 持续学习 + DoRA 高效微调 + 多节点一致性仲裁

## 职责

- 云端 Replay Buffer 捕捉环境演变，长周期重训练（`u_t = 2`），DoRA 增量微调
- 重训练产出统一走模块 A 的 AutoTailor 流水线**再编译**，以权重差量下发边侧热更新
- **多节点一致性仲裁（本次新增 ★）**：云端 VLM 基于跨节点全局上下文，检测重叠感知区域
  的决策冲突并下发一致化决策；边侧保留冲突回滚机制

## 对标指标

| 指标 | 要求 |
|---|---|
| 多边缘节点决策冲突比例 | ≤ 5% |
| 冲突解决成功率 | ≥ 90% |

## 对外接口（详见 `docs/接口契约_v0.md`）

- `u_t=1`：只下发轻量 Penv + ωt（对接模块 B）
- `u_t=2`：重训练 → AutoTailor 再编译（对接模块 A）→ 权重差量热更新下发
